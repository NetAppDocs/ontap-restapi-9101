= Manage the SnapLock ComplianceClock
:imagesdir: ./media/

[.lead]
Control the system's SnapLock ComplianceClock to establish the expiry time for SnapLock objects. Initialize this clock to ensure regulatory compliance, but note that once set, it cannot be modified.

This API manages the ComplianceClock of the system. ComplianceClock determines the expiry time of the SnapLock objects in the system. The user can initialize the ComplianceClock once and when it is set, it cannot be changed by the user.
