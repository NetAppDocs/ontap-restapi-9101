= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configuration to manage secure communication within your network environment. Use these endpoints to retrieve current status and apply updates as needed.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
