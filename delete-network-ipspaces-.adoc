= Delete an IPspace object
:imagesdir: ./media/

[.lead]
Deletes an IPspace object to remove its network configuration and associated settings from the system. Use this operation when an IPspace is no longer needed or is being reconfigured.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/network/ipspaces/{uuid}`#

== Introduced in

ONTAP 9.6

== Related ONTAP commands

* `network ipspace delete`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|IPspace UUID

|===

== Response

```
Status: 200, Ok
```
