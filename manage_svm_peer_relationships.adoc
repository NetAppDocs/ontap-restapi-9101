= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
SVM peer endpoints enable you to establish and manage peering relationships between storage virtual machines. Use these APIs to create, view, update, and delete SVM peers, facilitating shared resources and collaboration across your storage environment.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
