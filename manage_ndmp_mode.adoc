= Manage NDMP mode
:imagesdir: ./media/

[.lead]
Manage NDMP mode endpoints to configure and update the mode settings for NDMP, choosing between SVM-scope or node-scope based on your requirements.

You can use this API to manage NDMP mode: SVM-scope or node-scope.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----
